关于本页

本仪表盘由 GitHub Actions 定时工作流自动生成。它定期抓取 Hypixel SkyBlock 公共 API， 并把每次响应与上一次快照做比对，新增 / 删除 / 修改的字段会以代码审核风格记录在上方的变更日志中。 页面顶部的「当前版本」来自 collections 与 skills 两个资源接口的 version 字段： 由于 Hypixel 分批更新时两个接口不一定同时切换，只有两者版本一致才会确认新版本；不一致时保持上次稳定版本并显示「版本同步中」， 避免版本号来回跳。版本切换单独记录在「版本记录」面板，不混入端点内容变更日志。 集市（bazaar）的价格波动已被过滤，仅追踪商品的结构性增删。 资源包（packs）端点每次都会取 packFormat 数值最大的版本（该数字随 MC 更新变化）， 在官方哈希变化时下载 zip 并解压，按文件内容哈希比对包内文件的增删改； 被修改的文本文件只展示变化片段并标红标绿，新增文件只标绿。 Bingo 端点（bingo）记录每期任务的发布时间、开始与结束时间，并以 5×5 方格 列出全部任务（从左到右、从上到下，点击格子查看完整文案）； 倒计时把 start / end 的 epoch 毫秒交给浏览器逐秒计算， 不受 Actions 抓取延迟影响； 任务文案里的 Minecraft 颜色码（§）会按官方配色还原， 全服进度只用于展示、不参与变更比对。 限时特卖（firesales）端点每次运行都会重新抓取（特卖开始前官方可能调整时间/数量/价格）， 每期特卖独立成卡展示价格与数量，「显示额外数据」按钮可展开全部期次与原始 JSON。 若任一接口或资源包下载失败，本次运行不会改动仓库里的任何数据。
